# 从合同 Markdown 中拆分内嵌附件

## 摘要

在合同组织评审接收到 Markdown 合同正文后，先识别合同文本中独立成行的内嵌附件标题，将对应附件内容从主合同正文中移除，并作为附件文本并入后续附件列表。

## 动机

部分合同会把附件直接写在合同正文 Markdown 末尾。如果附件内容继续混在主合同正文中，会干扰首页、签章、金额付款等正文抽取，也不利于 B-4 按附件逐个检查。也会造成合同正文文本过长，导致模型上下文超长。

## 范围

- 识别主合同 Markdown 中独立成行的附件标题。
- 将每个内嵌附件拆成独立附件文本。
- 从主合同正文中移除已拆出的附件内容。
- 将拆出的附件与请求中已有上传附件合并。
- 保持后续 A-1a/A-1b/A-3/A-4/B-1/B-4 检查逻辑不变。

## 非目标

- 不新增 LLM 调用。
- 不改变上传附件接口格式。
- 不改变 B-4 附件内容一致性规则。
- 不解析非 Markdown 文件或 OCR 内容。
- 不识别正文句子中的“详见附件一”“附件一式三份”等非标题文本。
